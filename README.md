# Recipe Sharing Platform

A Java web-based application where users can view and share recipes.

## Team Members
- Sachin Singh — Admin / Team Leader
- Pranjal Singh — Team Member
- Ujjwal Babu — Team Member

## Technologies Used
- Java
- JSP
- Servlets
- JDBC
- MySQL
- HTML
- CSS
- Apache Tomcat

## Features
- View available recipes
- Add new recipes
- Store recipes in MySQL database
- Display saved recipes dynamically
- Simple and responsive RecipeHub interface

## Database
The project uses MySQL for storing recipe details such as recipe name, ingredients, instructions and description.

## Project Type
Java Web Application
